# FileMate Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or executing-plans. Steps use checkboxes.

**Goal:** 实现 V2 首版调查、审核、执行、恢复闭环及 dsh Web 接入。
**Architecture:** dsh 唯一 Agent 循环；TypeScript 插件适配 Python 业务 API；PostgreSQL 存业务状态。
**Tech Stack:** dsh/TypeScript, Python/FastAPI/SQLAlchemy/psycopg/Alembic, PostgreSQL.
**Spec:** ../../technical-design-v2.md

## Global Constraints
- Windows 本机；只操作显式授权根目录；不永久删除、不覆盖、不跨盘移动。
- 审核绑定计划版本/hash，不对模型开放批准和执行。
- PostgreSQL 为运行时数据库；不以 SQLite 代替 PG。
- dsh 原 Web UI，插件增加业务页面；无独立聊天 UI。
- pgvector/OCR/Excel 为后续阶段。

## Review Focus
- Windows 路径别名、junction、大小写和目标竞争：安全测试必须拒绝越界和覆盖。
- 审核后变更、重复提交：版本/hash 和任务唯一约束。
- 文件已移动而日志未完成：恢复核对，不盲目重试。
- 浏览器与 Agent 身份混淆：内部工具令牌不能调用审核接口。
- dsh 版本漂移：对实际安装版本编译/集成，不伪造 SDK。
